# 496. Next Greater Element I

## Problem Statement

Given two distinct integer arrays `nums1` and `nums2`, where `nums1` is a subset of `nums2`, find the next greater element for every element of `nums1`.

The next greater element of an element `x` is the first greater element to the right of `x` in `nums2`.

If there is no next greater element, return `-1`.

## Example

### Input
```text
nums1 = [4,1,2]
nums2 = [1,3,4,2]
