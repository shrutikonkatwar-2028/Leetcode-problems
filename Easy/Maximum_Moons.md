# Maximum Moons

- **Difficulty:** Easy
- **Language:** C++
- **Topics:** Arrays, Loops, Maximum, Summation

## Problem Statement

Given `N` rows and `M` values in each row, calculate the sum of values in every row and find the maximum row sum.

## Approach

- Read `N` and `M`.
- For each row, calculate the sum of its `M` values.
- Keep track of the maximum sum.
- Print the maximum sum.

## Complexity Analysis

- **Time Complexity:** O(N × M)
- **Space Complexity:** O(1)

## Concepts Used

- Nested Loops
- Summation
- Maximum Value
