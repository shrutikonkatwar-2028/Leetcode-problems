# Lexicographically Greater Palindromic Permutation

## Problem Description

Given two strings `s` and `target`, both of length `n`, consisting of
lowercase English letters, return the lexicographically smallest string
that:

1. Is a permutation of `s`.
2. Is a palindrome.
3. Is strictly greater than `target`.

If no such permutation exists, return an empty string.
